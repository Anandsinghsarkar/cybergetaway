Website integration

Use Cyber Payment checkout from another website or web app.

Important: the API key must stay on your website's backend/server. Never place it in HTML, browser JavaScript, a public repository or a mobile app. A payment redirect or screenshot is not proof of payment.

1. Create payment from your backend

Send the order ID and dynamic amount from your server. The response includes a unique checkout URL.

POST https://YOUR-CYBERGETAWAY-HOST/api/gateway/payment-intents Content-Type: application/json X-API-Key: YOUR_MERCHANT_API_KEY { "orderId": "ORDSHOP12345", "amount": 249.50, "customerName": "Customer", "returnUrl": "https://your-website.example/payment-return" }

2. Node.js backend example

Put these environment variables on your website server, not in frontend code.

const response = await fetch( process.env.CYBERGETAWAY_URL + '/api/gateway/payment-intents', { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-API-Key': process.env.CYBERGETAWAY_API_KEY }, body: JSON.stringify({ orderId: 'ORDSHOP12345', amount: 249.50, customerName: 'Customer' }) } ); const payment = await response.json(); if (!response.ok) throw new Error(payment.error); res.json({ checkoutUrl: payment.checkoutUrl });

3. Redirect customer to checkout

window.location.href = checkoutUrl;

Your website receives the checkout URL from its own backend and redirects the customer's browser to it.

4. Check payment status on your server

GET /api/gateway/payment-intents/ORDSHOP12345 X-API-Key: YOUR_MERCHANT_API_KEY

Only fulfil your own order after the authenticated status is PAID. This app changes an order to PAID only after the merchant manually verifies the bank/UPI transaction.

Security & verification

This is a single-merchant UPI checkout and payment-tracking application, not a regulated payment gateway. It does not automatically verify bank credits, settle funds, or process debit/credit cards. Verify each transaction in your bank/UPI app before marking it paid. Never request a customer's UPI PIN, OTP, CVV or banking password.
