How it works

Three steps from order to confirmed payment.

Create the order

Your backend calls the API with an order ID and amount, and gets a checkout URL.

Customer pays

They pay through any UPI app using the app button, QR code or UPI ID.

You confirm

Verify the credit in your bank or UPI app and mark the order paid.

Website integration

Call this endpoint from your website's backend using your merchant API key.

POST /api/gateway/payment-intents Content-Type: application/json X-API-Key: YOUR_MERCHANT_API_KEY { "orderId": "ORDORDER12345", "amount": 249.50, "customerName": "Customer", "returnUrl": "https://your-site.example/payment-return" }
Security notice: Call this endpoint only from your server and never expose the API key in browser code. A redirect or screenshot is not proof of payment. Check each UPI transaction in your bank records before marking an order paid. This is a merchant checkout and tracking tool, not a regulated payment gateway.
