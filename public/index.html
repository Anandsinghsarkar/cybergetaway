Website integration

Your website backend creates a payment intent using the merchant API key. The API responds with a checkout URL that you can send to the customer.

POST /api/gateway/payment-intents
Content-Type: application/json
X-API-Key: YOUR_MERCHANT_API_KEY

{
  "orderId": "ORDORDER12345",
  "amount": 249.50,
  "customerName": "Customer",
  "returnUrl": "https://your-site.example/payment-return"
}
Security & payment notice: Call this endpoint only from your website's backend. Never expose the API key in browser JavaScript. A redirect, screenshot, or customer message is not proof of payment. UPI transactions must be checked against the merchant's actual bank/UPI records before marking an order as paid. This is a merchant checkout and tracking tool, not a payment gateway or automatic bank-verification service.
